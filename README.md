# Student-Management-System
This is a simple C++ console-based project that allows you to manage student records using file handling. It supports:

- Adding new student records
- Displaying all students
- Searching for a student by roll number
- Updating existing student details
- Deleting a student record

## Features

- Written in C++
- Uses file I/O to store data in `students.dat`
- Easy-to-use menu-driven interface
